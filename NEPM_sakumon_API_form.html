🔒【名簿の使い捨て運用と個人情報の取り扱い】
  • 【作成のたびに読み込む】下のテンプレートをダウンロードし、既存の名簿から必要な情報をコピーして使います。
  • 【使い捨て】読み込んだ名簿データはこの画面で一時的に使用します。GAS出力後に「リセット」を押すと、画面上の名簿・入力内容・生成結果を消去します。
  • 【保存しない】名簿をJSON等で保存・再読み込みする機能は設けません。ブラウザの保存領域への永続保存もしません。
  • 【慎重な取り扱い】名簿ファイルは個人情報です。学校のルールに従って厳重に保管し、第三者に渡したり公開場所へ置いたりしないでください。
  • 【権限の分離と確認】採点者・管理者のみが本番フォームと採点シートにアクセスできます。共有教員には生徒の回答が見えない「配布用テンプレートのコピー（回答受付停止済）」が自動作成されます。
  • 【コードの取り扱い】出力されたGASコードには名簿情報が含まれます（名簿ありモードの場合）。完成コードをAIサービスへ再送信しないでください。
  • 【名簿なしモード】名簿を使わない簡易モードを選ぶと、個人情報（氏名・メールアドレス）は一切読み込みません。

名簿があるメリット
  • 本人の自動特定：メールアドレスで氏名を自動表示し、名簿にないアカウントの回答は「無効」と判定します。
  • 入力ミス・なりすましの防止：生徒は出席番号を選ぶだけ（氏名の誤字なし）。選んだ番号とメールが合わなければ「⚠️番号不一致」を表示します。
  • 権限の自動設定：採点者・管理者への共有や、共有教員向けの配布用コピーを、名簿の役割欄から自動で設定します。
名簿なしの場合：生徒が氏名を自由入力するため、誤字やなりすましは検知できません。採点者・管理者・共有教員への自動共有もなく、作成した教員のみがアクセスできます。少人数や試用に向いています。

個人情報の取り扱いについて
このファイルには個人情報が含まれます。厳重に保管し、第三者に渡したり、公開場所へ保存したりしないでください。学校のルールに従い、慎重に取り扱ってください。作問・配信環境の作成後は、画面の「リセット」を押してください。

作成データをコピーしてGeminiへ送信

🧩 手元の名簿・共有設定をGASコードへ安全合体（ローカル処理）

      
Geminiから出力されたGASコードを下の枠に貼り付けると、問題データを厳密検証したうえで、手元の名簿データ・権限分離設定が合体された完全版GASコードが生成されます。

  1. 上の緑色の「完成版GASコードをコピー」をクリックします。
    2. 
            
  2. Googleスプレッドシートを開き、メニューの「拡張機能」→「Apps Script」を選びます。
    3. 
            
  3. Apps Scriptエディタで「コード.gs」を開き、最初から記載されているサンプルコードをすべて削除します。
    4. 
            
  4. コピーした完成版GASコードを貼り付け、保存します。その後、コード内の作成関数を選んで実行します。初回はGoogleの権限確認が表示される場合があります。
