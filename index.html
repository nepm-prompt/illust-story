Version 1.3 — 2026-09-21

・ChatGPTで実行パッケージがMarkdownファイルとして扱われ自動開始しない場合の簡易起動操作を追加。停止した場合はチャットに「スタート」と入力する運用とし、長いTransport説明を簡略化

・Provider Execution ProfileにOutput Language Policyを追加。ユーザー向け表示、REASON、CANONICALの属性値は日本語とし、JSONキー、PASS / FAIL / UNKNOWN、READY / COMMITTED / ESCALATED等の制御語・状態値は英語固定。character_canonical_lockedは初期生成時に日本語で定義し、Canonical Lock後は翻訳・言い換え・要約による変更を禁止

・埋め込みVer.7.5 SPEC本体は変更なし



Version 1.2 — 2026-09-21

・ChatGPTで長文貼り付けがカード化された場合でも、実行パッケージを「処理対象の文書」ではなく「この会話の実行仕様」として解釈させやすくするため、生成される実行パッケージ末尾に実行開始指示を追加。要約・校正・変換を行わず、追加確認なしで連続イラストストーリーの生成を開始するよう明示



Version 1.1 (fixed) — 2026-09-21

・「5. 詳細な状態表示（JSON）」の選択が生成パッケージへ全く反映されていなかった配線漏れを修正。Persistent State（次ターンへ引き継ぐ最小情報）とDiagnostic Log（検証用の観測・判定詳細）を分離し、jsonview=OFFでは圧縮STATE行のみ、jsonview=ONでは従来通りフルJSON State Blockを出力する方式に変更（Output Mode節を新設、SPEC本体は無変更）

・PoC 0.3由来のHuman Artifact Gate UI（画像目視確認ボタン・Canonical Command正規化・hostState管理一式）を削除。校務PC一画面運用で画面往復（作業コンテキストの切替）が発生する構成をやめ、生成後はLLMチャット内で「次へ／再生成 ○○を直して／終了」とテキストで進める運用に一本化。Geminiの画像未表示に関する注意書き（geminiWarning）のみ維持

・(追記)ChatGPTでの実機テストで、Rollback発生後にcharacter_canonical_lockedの値(三つ編み・長剣の左右など)が誤った生成画像側に引きずられて反転する不具合を確認。Output Mode(COMPACT)の指示文にあった「要約」という語が毎ターンの再生成を誘発していた可能性が高いと判断し、Execution Instructionsに「Canonical Lock」規則(character_canonical_lockedは設定フェーズ後は不変、観測結果で書き換え禁止)を新設。COMPACT/FULL両モードの指示文からもこの規則を参照するよう修正。SPEC本体側にも同種の明示規定がない点は既知の別課題として保留
